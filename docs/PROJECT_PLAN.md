## 4. 风险登记册

| 风险 | 等级 | 说明 | 应对 |
| --- | --- | --- | --- |
| Garth 已弃用/认证改版 | 高 | 官方标注新登录可能失效 | 按当前 garth API 实现；登录失败需跟进 Garmin 认证变化，或替换底层库 |
| garth 内部 token 结构差异 | 中 | 不同版本字段名可能变化 | 采用原生 save/resume 目录持久化，降低耦合 |
| 中国区活动上传国际区政策限制 | 中 | 未验证 Garmin 是否允许 | 提供手动触发与日志，便于观察；失败有 partial/error 标记 |
| 需真实双账户联调 | 中 | 自动化测试仅覆盖非网络逻辑 | 交付联调说明文档，指导用户用真机验证 |
| NAS 时区/路径 | 低 | 同步时间依赖 TZ | docker-compose 注入 TZ=Asia/Shanghai |
