# 飞牛 NAS（fnOS）部署指南 · 纯图形界面版

本文面向飞牛私有云（fnOS）用户，全程用**网页 / 桌面图形界面**完成部署，不碰命令行。
部署后访问 `http://<飞牛NAS的IP>:1234`。**首次打开需设置管理员账号（用户名+密码），
之后每次访问输入用户名密码登录**（登录有效 24 小时，连续 5 次密码错误锁定 1 小时）。

> 你本机是 macOS（arm 架构），飞牛 NAS 是 x86_64，架构不同。**不要在 Mac 上 build 后拷贝镜像**，
> 而是把源码整目录传到 NAS，让 NAS 自己 build（compose 已内置清华镜像，构建较快）。

---

## 一、把源码传到飞牛

两种方式任选：

**方式 A：飞牛「文件」App 上传（最简单）**
1. 在 Mac 上把 `garmin` 整个文件夹压缩成 `garmin.zip`。
2. 飞牛桌面打开「文件」App → 进 `Docker` 目录 → 新建文件夹 `garminsync`。
3. 把 `garmin.zip` 上传进 `Docker/garminsync`，右键解压，得到 `Docker/garminsync/garmin/...` 一整套文件。
   - 也可直接把解压后的 `garmin` 文件夹改名成 `garminsync` 上传，只要最终目录下有 `docker-compose.yml` 即可。

**方式 B：SMB / SFTP 拖拽**
1. 飞牛「设置 → 文件服务」开启 SMB（或 SFTP）。
2. 在 Mac 访达里连上飞牛共享，直接把 `garmin` 文件夹拖到 `Docker/garminsync/`。

> 不需要准备 `.env`，不传也能正常部署；鉴权账号在首次打开网页时设置，无需预配。

---

## 二、飞牛 Docker 图形界面创建项目

1. 飞牛桌面打开 **Docker** 应用。
2. 左侧点 **项目（Compose）** → 右上角 **创建项目**。
3. 填写：
   - **项目名称**：`garminsync`
   - **路径**：选择第一步上传的目录（包含 `docker-compose.yml` 的那一层）
   - **Compose 文件**：自动识别 `docker-compose.yml`（也可手动上传）
4. 点 **下一步** 进入环境变量（一般保持默认即可）：
   - `PORT`：`1234`（与端口映射一致，一般不用改）。
   - `DATA_DIR`：`/data`。
   - `TZ`：`Asia/Shanghai`。
5. 确认存储 `./data:/data` 无误 → 点 **创建 / 启动**。

> 本项目使用 **bridge 网络 + 端口映射**（`1234:1234`），不占用独立 IP。
> 访问地址为 `http://<飞牛NAS的IP>:1234`（本机为 `http://10.10.200.20:1234`）。

---

## 三、等待构建与启动

- 首次会**构建镜像**（拉 Python 基础镜像 + 装依赖，清华镜像约几分钟），请耐心等进度条走完。
- 创建后在「容器」列表看到 `garminsync` 状态为 **运行中** 即成功。
- 点容器「日志」可看到 `Application startup complete`。

常用图形操作：
- **停止**：容器右键 → 停止。
- **重启**：容器右键 → 重启。
- **更新代码后重建**：项目右键 → 重新创建 / 拉取并重建（compose 会重新 build）。

---

## 四、访问与配置

1. 浏览器打开：`http://10.10.200.20:1234`（飞牛 NAS 的 IP + 端口映射）。
   - 飞牛自带浏览器、局域网内手机/电脑均可访问。
   - 若访问不通，详见下方「常见问题 → 网页打不开」。
2. 首次打开：设置管理员用户名 + 密码（至少 8 位）→ 进入主面板。
3. 之后每次访问需输入用户名密码登录；右上角可退出登录。

---

## 五、配置佳明账户并同步

1. 在「① 佳明账户」填**佳明中国区**邮箱+密码 → 登录 → 手机收短信 → 填验证码；下方填**佳明国际区**邮箱+密码 → 登录。
2. 可选：「② iGPSPORT 迹驰」绑定迹驰账号（已登录时随活动同步一并上传）；「⑤ 佳明健康数据」「⑥ 小米体重同步」按需开启。
3. 「③ 同步设置」选频率（10 分钟~6 小时）并启用。
4. 「④ 同步状态」点「立即同步」试一次，看日志 `success / partial / error`。

---

## 六、数据备份与迁移

- 所有数据在 `garminsync/data/`：`app.db`（设置、同步记录、Garmin token）。
- 备份：飞牛「文件」App 直接复制 `data/` 文件夹。
- 迁移：源码 + `data/` 一起拷到新 NAS，重新走第二~四步。

---

## 七、常见问题（图形界面）

| 现象 | 处理 |
| --- | --- |
| 创建项目报「找不到 docker-compose.yml」 | 路径要选到**包含**该文件的目录那一层 |
| 构建很慢 / 卡住 | compose 已用清华镜像；确认飞牛能联网，或重新创建重试；可看容器日志 |
| 网页打不开 | 确认容器在运行；用飞牛 NAS 的 IP（如 `10.10.200.20`）+ `1234` 端口访问；确认端口映射存在、容器日志无报错 |
| 中国区登录报认证错误 | 见 `docs/RISKS_AND_SETUP.md`：garth 可能随 Garmin 改版失效 |
| 短信码超时 | 验证码默认等待 300 秒（`MFA_WAIT_SECONDS`），收码慢请重登 |

---

## 八、已知限制（部署前必读）

- 基于 garth 0.4.47，garth 已不再积极维护；Garmin 认证改版后**新账户登录可能失效**，请先小范围联调一次。
- 跨区（中国→国际）同步请遵守 Garmin 服务条款。
- 真实双账户 + 中国区短信联调必须在你的 NAS/浏览器上完成。
